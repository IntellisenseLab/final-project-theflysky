Activate venv
source .venv/bin/activate

Run your script
python [].py

When done
deactivate

SSH into the Pi:
ssh flysky@<pi-ip-address>

Install mDNS support (do once after first boot):
sudo apt update
sudo apt install avahi-daemon
sudo systemctl enable avahi-daemon
sudo systemctl start avahi-daemon

Check hostname:
hostname

Then you can SSH using:
ssh flysky@qbot.local
